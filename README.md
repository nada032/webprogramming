Runs the app in the development mode.\

### `npm test`

See the section about [running tests](https://facebook.github.io/create-react-app/docs/running-tests) for more information.

### `npm run build`

Builds the app for production to the `build` folder.\
It correctly bundles React in production mode and optimizes the build for the best performance.

The build is minified and the filenames include the hashes.\
Your app is ready to be deployed!

See the section about [deployment](https://facebook.github.io/create-react-app/docs/deployment) for more information.

### `npm run eject`

**Note: this is a one-way operation. Once you `eject`, you can't go back!**

If you aren't satisfied with the build tool and configuration choices, you can `eject` at any time. This command will remove the single build dependency from your project.

Instead, it will copy all the configuration files and the transitive dependencies (webpack, Babel, ESLint, etc) right into your project so you have full control over them. All of the commands except `eject` will still work, but they will point to the copied scripts so you can tweak them. At this point you're on your own.

You don't have to ever use `eject`. The curated feature set is suitable for small and middle deployments, and you shouldn't feel obligated to use this feature. However we understand that this tool wouldn't be useful if you couldn't customize it when you are ready for it.

1. 수거 및 보상 방법 (브랜드별 요약)
① 올리브영 (뷰티사이클)
수거 방식: 매장 직접 방문 (개수 제한 없음 하지만 1일 1회 보상으로 제한)

주의: 복합몰, 백화점, 마트, 공항, 역사 내 입점 매장은 수거 불가

브랜드 제한: 없음 (모든 브랜드 제품 수거 가능)

보상 방식: 올리브영 앱 할인 쿠폰 즉시 발급 (하루 1회 제한)

혜택: 기획전 내 2만 원 이상 구매 시 2,000원 ~ 3,000원 할인권

② 아모레퍼시픽 (아모레리사이클)
수거 방식: 매장 방문 또는 온라인 신청 (온라인은 10개 이상일 때만 무료 수거 가능)

주의: 대형마트 입점 매장, 편집샵 매장은 수거 불가

브랜드 제한: 아모레퍼시픽 그룹 내 브랜드만 가능 (설화수, 미장센, 헤라, 아이오페, 마몽드, 라네즈, 려, 일리윤)

주의: 에스쁘아, 에뛰드, 이니스프리 매장에서는 아모레 공병을 받지 않음 (독립 로드샵)

보상 방식: 뷰티포인트 적립 (월 최대 1,000P 제한 / 누적 가능)

혜택:온라인 신청 시 묶음당(10개이상) 1,000P 지급 / 매장방문 시 개당 300p

③ 이니스프리 (bottle Re:Play)
수거 방식: 매장 방문 또는 온라인 신청 (10개 이상일 때 온라인 수거 신청 가능)

주의: 대형마트 입점 매장, 백화점, 아울렛, 면세점 지점은 수거 불가

브랜드 제한: 이니스프리 제품만 가능

보상 방식: 뷰티포인트 적립 (월 최대 3,000P 제한_온라인,매장 합)

혜택: 개당 300P (시즌 이벤트에 따라 추가 포인트 지급)

④ 러쉬 (BIB: Bring It Back)
수거 방식: 모든 러쉬 지점 매장 방문 (5개 단위 지참)

브랜드 제한: 러쉬 제품만 가능 (블랙팟, 화이트팟)

보상 방식: 매장 즉시 할인 또는 제품 교환

혜택: 공병 개당 1,000원 즉시 할인 OR 공병 5개 지참 시 마스크팩 1개 교환

2. 수거 가능 품목 안내
⚠️ 전 브랜드 공통 수거 불가능 품목 (절대 제외):

기본 가능 품목: 스킨케어, 바디케어, 헤어케어 제품 일체

[브랜드별 상세 기준]
올리브영: 스킨케어, 클렌징, 헤어케어, 선케어, 바디케어, 핸드크림, 쿠션, 팩트

아모레퍼시픽: 스킨케어(스킨, 로션, 크림, 클렌징), 헤어, 바디, 핸드케어, 메이크업(쿠션, 팩트), 향수 용기

이니스프리: 스킨케어, 선케어, 클렌징, 헤어제품, 핸드크림, 향수,방향제, 유리 용기, 플라스틱 재질 용기, 네일리무버 공병

러쉬: 용량 45g 이상이며 소재 마크가 PP인 블랙팟 및 화이트팟 용기

3. 오염 방지! 올바른 세척 방법
공통 필수 사항: 내용물이 남지 않도록 깨끗이 세척한 후 완전히 건조해야 곰팡이나 오염 없이 재활용할 수 있습니다.

올리브영: 용기 내부 깨끗이 씻어 말리기 ➡️ 부착된 라벨 스티커 제거하기

아모레퍼시픽 / 이니스프리 (제형별 세척 팁):

액체류: 내부를 깨끗이 비우기

크림/밤 제형: 휴지로 내부 내용물을 먼저 닦아낸 후, 주방세제로 가볍게 세척하여 건조

오일 제형: 따뜻한 물에 주방세제 한 방울을 섞어 깨끗이 세척 후 건조

튜브류: 용기를 가위로 반으로 잘라 내부를 완전히 비운 뒤, 잘린 용기 조각 전체를 반납

쿠션/팩트류: 내부 리필 플레이트 분리 및 거울/퍼프 제거 후 본체만 반납

러쉬: 내부 세척 ➡️ 완전 건조 후 반납

4. 우리가 반납한 공병의 재활용 방식 (환경 효과)
올리브영: 올리브영 매장 내 집기(매대, 바구니) 원료로 업사이클링 / 올영 자체 브랜드 제품 생산 시 재생 플라스틱(PCR) 용기로 재투입 / 생활용품(빗, 파우치 등) 제작

아모레퍼시픽: 업사이클링 벤치 제작, 공공 예술 작품 기증, 매장 인테리어 자재, 타 제품 원료 소재 활용

이니스프리: 새로운 이니스프리 제품 용기로 리사이클링 (전체 유리 용기 중 60%를 재생 플라스틱 및 PCR 유리 소재로 전환 생산)

러쉬: 새로운 러쉬 제품 용기(블랙팟) 또는 용기 뚜껑으로 100% 재사용

- 공병 재활용 효과
  * 4개 브랜드 평균 연간 최소 약 295톤의 화장품 공병이 일반 쓰레기 매립·소각장으로 가는 대신 완벽하게 자원으로 회수
  * 연간 약 690 톤의 이산화탄소(CO2) 감축
  * 가솔린 승용차 한 대가 지구를 약 90바퀴 돌 때 나오는 온실가스 배출량을 매년 완전히 상쇄
  * 30년생 소나무 약 104,500 그루가 1년 동안 흡수해야 하는 탄소량을 공병 재활용만으로 해결
